# 常考函数的一致连续性速查表

判定四步法：
1. **闭区间 $[a,b]$ + 连续** $\Rightarrow$ 一致连续（紧性，直接写）。
2. **有限开区间 $(a,b)$ + 连续 + 两端单侧极限存在** $\Rightarrow$ 一致连续（延拓 + 紧性）。
3. **无界区间**：先看增长 —— 若 $\lvert f(x)\rvert$ 超线性增长（$\lvert f(x)\rvert/x\to\infty$）或某点附近无界，则**不一致连续**；若两端可以用极限压住（或可拆成 $(-\infty,-A]\cup[-A,A]\cup[A,+\infty)$），则一致连续。
4. **有限区间但不满足 1、2**：多半是端点处振荡不衰减，用**点列**否证。

## 一、一致连续（✓）

| 函数 | 区间 | 依据（不等式） |
| --- | --- | --- |
| $\sin x,\ \cos x$ | $\mathbb{R}$ | $\left\lvert\sin x-\sin y\right\rvert\le\left\lvert x-y\right\rvert$（和差化积） |
| $x$、$\lvert x\rvert$ | $\mathbb{R}$ | Lipschitz，$L=1$ |
| $\sqrt{x}$ | $[0,+\infty)$ | $\left\lvert\sqrt x-\sqrt y\right\rvert\le\sqrt{\lvert x-y\rvert}$（Hölder $1/2$） |
| $x^{\alpha}$，$0<\alpha\le1$ | $[0,+\infty)$ | $\left\lvert x^{\alpha}-y^{\alpha}\right\rvert\le\lvert x-y\rvert^{\alpha}$ |
| $\sqrt{1+x^{2}}$ | $\mathbb{R}$ | $\le\lvert x-y\rvert$；无界但一致连续 |
| $x^{2},\ x^{3},\ x^{n}$ | 任意**有界**闭区间 | 紧性；$\lvert x^{n}-y^{n}\rvert\le n M^{n-1}\lvert x-y\rvert$ |
| $\dfrac{1}{x}$ | $[a,+\infty)$，$a>0$ | $\dfrac{\lvert x-y\rvert}{xy}\le\dfrac{\lvert x-y\rvert}{a^{2}}$ |
| $\ln x$ | $[a,+\infty)$，$a>0$（如 $[1,+\infty)$） | $\lvert\ln x-\ln y\rvert\le\lvert x-y\rvert\ (x,y\ge1)$ |
| $x\ln x$ | $(0,1]$（补 $f(0)=0$） | 连续延拓，紧性 |
| $e^{x}$ | $(-\infty,a]$ | $\left\lvert e^{x}-e^{y}\right\rvert\le e^{a}\lvert x-y\rvert$ |
| $e^{-x}$、$e^{-x^{2}}$ | $[0,+\infty)$ / $\mathbb{R}$ | $e^{-x}$ 有界导数；$e^{-x^{2}}$ 用两端极限 $0$ + 拆段 |
| $\arctan x$ | $\mathbb{R}$ | 奇函数、趋向 $\pm\pi/2$ + 拆成三段 |
| $\dfrac{x}{1+x^{2}}$、$\dfrac{\sin x}{x}$（补 $f(0)=1$） | $\mathbb{R}$ | 连续 + 两端极限 $0$ + 拆段 |
| $\dfrac{1}{1+x^{2}}$ | $\mathbb{R}$ | 同上 |
| $x\sin\dfrac1x$ | $(0,1]$ 或 $\mathbb{R}$ | $\lvert f\rvert\le\lvert x\rvert$，在 $0$ 处连续延拓；$\lvert x\rvert\ge1$ 段 Lipschitz |
| $x^{2}\sin\dfrac1x$、$\sqrt{x}\sin\dfrac1x$ | $(0,1]$（补 $f(0)=0$） | 连续延拓后紧性 |
| 周期为 $T$ 的连续函数 | $\mathbb{R}$ | 在 $[0,T]$ 上紧性 + 平移 |
| 一致连续函数的**和、差、复合**（内层有界） | 同区间 | 直接用定义 |

## 二、不一致连续（✗）—— 附带点列反例

| 函数 | 区间 | 反例点列（$\lvert x_n-y_n\rvert\to0$，而函数值差有正下界） |
| --- | --- | --- |
| $x^{2}$ | $\mathbb{R}$ | $x_n=n,\ y_n=n+\frac1n$，差 $=2+\frac1{n^{2}}\ge2$ |
| $x^{3},\ x^{n}(n\ge2)$ | $\mathbb{R}$（同样超线性增长） | $x_n=n,\ y_n=n+\frac{1}{n^{n-1}}$ |
| $x^{\alpha}$，$\alpha>1$ | $[0,+\infty)$ | 同上（增长型） |
| $e^{x}$ | $\mathbb{R}$ | $x_n=n,\ y_n=n+\frac1n$，差 $\ge e^{n}/n\to\infty$ |
| $x\sin x$ | $\mathbb{R}$ | $x_n=2n\pi,\ y_n=2n\pi+\frac1n$，差 $\approx2\pi$ |
| $\sin\left(x^{2}\right)$ | $\mathbb{R}$ | $x_n=\sqrt{2n\pi},\ y_n=\sqrt{2n\pi+\frac{\pi}{2}}$，差 $=1$ |
| $\dfrac{1}{x}$、$\dfrac{1}{x^{2}}$、$x^{\alpha}(\alpha<0)$ | $(0,1)$ | $x_n=\frac1n,\ y_n=\frac1{n+1}$，差 $\to$ 常数 |
| $\ln x$ | $(0,1)$ | $x_n=e^{-n},\ y_n=e^{-(n+1)}$，差 $=1$ |
| $\sin\dfrac1x,\ \cos\dfrac1x$ | $(0,1)$ | $x_n=\frac{1}{n\pi},\ y_n=\frac{1}{n\pi+\pi/2}$，差 $=1$ |
| $\tan x$ | $\left(-\frac\pi2,\frac\pi2\right)$ | 端点无界（$x_n\to\frac\pi2$，$f\to\infty$） |
| $[x]$（取整） | 含整数为内点的区间，如 $[0,3]$ | 在整数处跳跃：$f(k^+)-f(k^-)=1$ |
| Dirichlet 函数 | 任何区间 | 处处不连续，谈不上一致连续 |
| $\dfrac{1}{\sqrt{x}}$ | $(0,1)$ | 在 $0$ 附近无界 |

## 三、五个「症状」对照

| 症状 | 结论 | 例 |
| --- | --- | --- |
| 区间内某点附近无界 | ✗ | $\frac1x$、$\tan x$、$\frac1{\sqrt x}$ 于 $(0,1)$ |
| 无穷远处超线性增长 | ✗ | $x^{2}$、$e^{x}$、$x\sin x$ 于 $\mathbb{R}$ |
| 端点极限不存在但函数有界（振荡不衰减） | ✗ | $\sin\frac1x$、$\sin(x^{2})$ |
| 端点极限存在（含补点后连续） | ✓ | $\sqrt x$、$x\sin\frac1x$、$\ln x$ 于 $[1,\infty)$ |
| 次线性增长且连续 | ✓ | $\sqrt x$、$\sqrt{1+x^{2}}$、$\arctan x$ |

## 四、易错三条

1. **有界 ⇏ 一致连续**：$\sin\frac1x$ 在 $(0,1)$ 上有界却不一致连续。
2. **无界 ⇏ 不一致连续**：$\sqrt{1+x^{2}}$、$x$ 在 $\mathbb{R}$ 上无界但一致连续。
3. **不是 Lipschitz ⇏ 不一致连续**：$\sqrt x$ 在 $[0,1]$ 上非 Lipschitz，但一致连续。
4. 找反例的区间必须是**开区间或无界区间**：$[a,b]$ 上连续的函数一定一致连续，别在那里白费力气。
